A tiny deterministic Python program that writes one line of deliberately terrible AI advice (140 characters or fewer) to /output/entry.txt for make.fun's Worst AI Advice bounty. The line is fixed, so every run produces the exact same text.

The advice itself is deliberately bad on purpose: it sounds like a confident assistant tip, names a concrete action, and would be a terrible idea to follow.

## Run it

```sh
python3 main.py
```
